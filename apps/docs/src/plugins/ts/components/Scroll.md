# Scroll

`ScrollPanel` / `ScrollPanelGroup` — scrollable container panels used throughout Steam's UI.

```ts
type ScrollPanelProps = { children?: ReactNode };
type ScrollPanelGroupProps = { children?: ReactNode };
```

### Usage

```tsx
import { ScrollPanel } from 'millennium';

<ScrollPanel>
	<div>Long content...</div>
</ScrollPanel>;
```
